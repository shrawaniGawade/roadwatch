# Implementation contract

This document records the implemented service boundaries and payloads. Shared TypeScript types are in packages/domain; operational APIs are in apps/api; the browser is in apps/web; camera and inference code is in services/edge and services/vision. See VALIDATION.md for executed checks and DEPLOYMENT.md for operating instructions.

Product name: RoadWatch. Next.js UI localhost:3000, NestJS API localhost:3001 (all endpoints /v1), Python vision localhost:8001. Browser uses /api/v1 proxied to API. PostgreSQL local port 55432, database roadwatch. DATABASE_URL is injected by the launcher. The workstation uses native PostgreSQL and explicitly reports local_approximation without PostGIS; the production Compose profile requires PostGIS. Operational records always use durable storage.

Shared package @roadwatch/domain exports types and pure logic, built by root before API. Use camelCase JSON. GET collections return arrays. GET /v1/dashboard returns DashboardData. API errors {message:string,code?:string}. Auth: POST /v1/auth/login {email,password}, GET /v1/auth/me, POST /v1/auth/logout; HttpOnly same-site session cookie. Server enforces tenant + role. Initial local admin comes from environment seed; no auth bypass. API CSRF protection via Origin allowlist for browser writes.

Routes:
- GET /v1/health, /v1/ready public; everything else authenticated except login.
- GET /v1/dashboard, /v1/roads, /v1/roads/:id, /v1/segments, /v1/defects, /v1/defects/:id, /v1/devices, /v1/surveys, /v1/work-orders, /v1/audit, /v1/settings.
- POST /v1/defects manual report with {roadId,segmentId?,type,latitude,longitude,description,depthMm?:number,lengthM?:number,widthM?:number,trafficExposure?:number,vulnerableContext?:number}. Manual measurements must remain estimated unless authorized survey verification.
- POST /v1/defects/:id/reviews {action:'confirm'|'reject'|'reopen',reason,expectedVersion}; expectedVersion required; 409 on conflicts. Reject/confirm only review-capable roles.
- POST /v1/work-orders {defectIds:string[],crew,description,dueAt}; only confirmed defects; assign atomically; planner/admin. POST /v1/work-orders/:id/transitions {action:'start'|'report_repair'|'verify'|'reopen',notes,expectedVersion}; same user cannot independently verify own repair.
- POST /v1/devices {name,kind:'vehicle'|'cctv'|'mobile',vehiclePlate?,cameraModel?}; provisioning returns one-time device token and ID.
- POST /v1/surveys {deviceId,name,roadIds:string[]}. POST /v1/surveys/:id/complete.
- POST /v1/uploads multipart form file + surveyId + capturedAt + latitude? + longitude? + calibrationId?; validate/store SHA256, create persisted job. GET /v1/jobs; POST /v1/jobs/:id/retry.
- GET /v1/media/:id authenticated streams private evidence. No permanent public paths.
- POST /v1/roads/import GeoJSON {type:'FeatureCollection',features:...} with properties name/code/owner/region and LineString geometry. Validate and derive segments. POST /v1/calibrations to save explicit calibration metadata for device. GET /v1/calibrations.
- GET /v1/reports/defects.csv and /v1/reports/summary (JSON snapshot); formula-safe CSV. GET /v1/reports/geojson.
- PATCH /v1/settings {organizationName,defaultRegion,retentionDays,priorityPolicy?}; versioned audit and open-priority recalculation. Retention is recorded policy; automatic evidence expiry is not enabled.
- GET/POST /v1/users and PATCH /v1/users/:id; administrator role, last-administrator protection, session revocation after password/role changes.
- POST /v1/devices/heartbeat, /v1/devices/:id/rotate-token, /v1/devices/:id/revoke; device ownership and immediate credential invalidation.
- GET /v1/notifications and POST /v1/notifications/:id/acknowledge; persistent internal inbox.
- POST /v1/jobs/:id/observations/:index/locate; authorized, idempotent reviewer placement of a retained unlocated observation with unknown location accuracy.

Shared types are authoritative in packages/domain/src/index.ts (canonical exported types). Important shapes: Road {id,name,code,region,owner,surface,lengthM,geometry:{type:'LineString',coordinates:[number,number][]},version,updatedAt}; Segment {id,roadId,name,chainageStartM,chainageEndM,coveragePct,lastSurveyAt,geometry}; Defect {id,code,roadId,roadName,segmentId,type,status,priority,severity,latitude,longitude,locationAccuracyM,chainageM,description,length,width,depth,area,confidence,source,observedAt,updatedAt,version,evidence:Evidence[],assessment:PriorityAssessment}; Measurement {value,unit,status,method,uncertainty95,reason?}; null means unknown. DefectType pothole/longitudinal_crack/transverse_crack/alligator_crack/patch_deterioration/raveling/edge_break/surface_deformation. Status candidate/confirmed/rejected/assigned/in_progress/repair_reported/closed. Priority P0-P3. Severity unknown/low/moderate/high. Evidence {id,mediaId,url,filename,mimeType,capturedAt,sha256,mask?:number[][],width?:number,height?:number}. Device {id,name,kind,status,vehiclePlate,cameraModel,lastSeenAt,latitude,longitude,calibrationStatus,uploadBacklog}. WorkOrder {id,code,defectIds,crew,description,status,dueAt,createdAt,updatedAt,version,repairReportedBy?,notes?}. AuditEvent {id,actor,action,entityType,entityId,createdAt,details}. Job {id,surveyId,mediaId,status,attempts,error,createdAt,updatedAt,pipelineVersion}. Vision API contract: GET /health and /ready; POST /v1/analyze multipart file plus metadata JSON string. Header X-Service-Key authenticates requests. Metadata {capturedAt,latitude?,longitude?,locationAccuracyM?,calibration?:object}. Result {pipelineVersion,model:{name,version,ready},quality:{eligible,reasons:string[]},detections:[{type,confidence,mask:number[][],bbox:number[],length?:Measurement,width?:Measurement,depth?:Measurement,area?:Measurement,latitude?:number,longitude?:number,locationAccuracyM?:number}],frameCount:number}. When trained compatible road model absent return explicit HTTP 503 model_not_configured, never simulated inference. Processing job must preserve media and failure reason. API performs worker HTTP call with private stored media, timeout/retries, no public URL reliance. The implemented queue uses PostgreSQL leases, transaction fencing, bounded retries and idempotent result commits. A separate SQL outbox worker creates internal notifications and checks overdue work orders. RabbitMQ and Temporal are not runtime dependencies.

Seed demo data is a deliberate local fixture, clearly labeled isDemo=true in UI and README. Real uploads never produce fake detections. Seed road data and coordinates illustrative Hyderabad area, not official maps or real hazard claims. Setup generates local credentials once; secret values remain outside Git. Fixtures contain no external personal data.


Upload metadata can also carry locationAccuracyM, JSON trajectory and maxSyncGapMs; per-image model results retain frame offsets, masks, measurement methods, calibration identifiers, pipeline/model version, artifact hash and source/license provenance. Idempotency-Key binds bytes and metadata; X-Content-SHA256 checks transport integrity. API file limit is 32 MiB; authenticated evidence supports byte ranges. The Next.js upload App Route streams to a fixed API origin and preserves these headers.

Production rewrites use the build-time API_ORIGIN, while the upload route uses its runtime value. Compose supplies matching origins. The approved public map style must also be supplied before building. Camera GPS alone does not identify the defect: calibrated projection and synchronized pose or an explicit reviewer estimate are required. The full numerical and tensor schemas are in services/vision/README.md.
